              Sobre o Open Banking
              A Dora usa o Pluggy para acessar seus dados bancários de forma segura via Open Banking regulado pelo Banco Central. Suas credenciais bancárias nunca passam pelos servidores da Dora — a conexão é direta entre você e o banco.

              Conectar banco
              Para conectar sua conta, você precisa do Item ID gerado pelo Pluggy para o seu banco. Você pode obtê-lo via dashboard.pluggy.ai ou via a API do Pluggy.
              🔒 O Item ID é criado após você autenticar seu banco no Pluggy. Ele representa a conexão autorizada com sua conta.
